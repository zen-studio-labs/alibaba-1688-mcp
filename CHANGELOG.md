# Changelog

## 0.1.0

First release.

- Remote MCP server with three sourcing tools: 1688 (阿里巴巴1688) wholesale products, Alibaba.com products and suppliers, and Alibaba.com supplier store reviews.
- Apify sign-in (OAuth) for Claude, ChatGPT, Cursor, VS Code, Codex and other remote MCP clients; token header as an alternative.
- Claude Code plugin with the 1688 & Alibaba.com skill: run flow for longer requests, input recipes, tool chaining and field sets.
- Client configuration examples, code examples for Python, JavaScript and HTTP, and an MCP Registry manifest.
- README in English and Simplified Chinese.
